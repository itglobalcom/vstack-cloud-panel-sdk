# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this SDK, please report it privately
so it can be addressed before public disclosure.

**Email:** support@vstack.com

Please include:

- a description of the issue and its impact;
- steps to reproduce (a minimal code sample if possible);
- the affected version(s) of the SDK.

Please do **not** open a public GitHub issue for security reports.

We will acknowledge your report as soon as possible and keep you informed about
the progress toward a fix.

## Supported Versions

Security fixes are released against the latest published version. We recommend
always using the most recent release.
