# Contributing

This GitHub repository is a read-only mirror. Development happens in an internal GitLab instance, and changes are synced here automatically.

## Issues

Bug reports and feature requests are welcome via [GitHub Issues](https://github.com/itglobalcom/vstack-cloud-panel-sdk/issues).

## Pull requests

Pull requests cannot be merged into this mirror directly. Maintainers will review proposed changes and apply accepted ones upstream; they will appear here with the next sync.

## Development

```bash
git clone https://github.com/itglobalcom/vstack-cloud-panel-sdk.git
cd vstack-cloud-panel-sdk
make test
```

Before proposing changes, make sure `make fmt`, `make vet`, and `make test` pass — CI enforces them.
